## YOLOv5

The detector training and inference source is pinned to commit `f9578796b8a64889aa9e66dc06914d19f40d338e`. Its upstream license is AGPL-3.0. The project fetches that source into an ignored working directory rather than copying it into this repository. Runtime Python dependencies have their own notices; review the exact pinned distributions before redistributing a bundled environment or weights.

## Data

This project uses only data generated by its own reproducible synthetic signal generator. It does not download, vendor, or claim results on DeepSig SPAWC 2021 or the Zenodo companion record `10.5281/zenodo.7799387`.

The Zenodo record's Rights field has not been verified in this project. No license conclusion is made about those files, and downloading them is not required. DeepSig access and license terms are also unverified. Check the current source records before using either dataset.
